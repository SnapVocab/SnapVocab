Mode: Operate. Native Android. This is a scoped composition redesign inside the
existing app world; do not create a second palette or shared control system.

The user confirmed **compact lists, one word at a time**. Preserve the working
flow: dictionary/scan saves → My words → own collection → topic or subtopic →
schema-generated editable TopicItem form. Runpod/team recovery and real-inference
testing were explicitly deferred by the user during this request.

word for detail; the folder action chooses its destination; overflow owns removal.

confirmation action. Never navigate into the form merely by selecting a row.
Show the full selected destination before confirmation. Back moves up each level
and clears the old selection. Unknown words, empty data, failures and pending
mutations remain explicit, and own collections are used.
